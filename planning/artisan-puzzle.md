# Artisan Puzzle Game

## 개요
"The Artisan of Glimmith" 스타일의 격자 드로잉 퍼즐 게임.
주어진 도형 모양에 맞게 격자 위에 마우스로 영역을 직접 그려서 채우는 퍼즐.

## 기술 스택
- HTML5 Canvas + 순수 JavaScript
- CSS (UI 스타일링)
- 배포: GitHub Pages

## 폴더 위치
`games/artisan-puzzle/`

---

## 핵심 메카닉

### 격자 (Grid)
- N x N 셀로 구성된 플레이 보드
- 각 셀은 빈 상태 / 색칠된 상태 / 잠긴 상태(배경)로 구분

### 마우스 인터랙션
- 좌클릭 + 드래그 → 셀 색칠
- 우클릭 + 드래그 → 셀 지우기
- 드래그 중 실시간으로 선택 영역 하이라이트

### 도형 검증 (Polyomino Validation)
- 우측 패널에 목표 도형(폴리오미노) 표시
- 플레이어가 색칠 완료 시 → 선택 영역이 목표 도형과 모양 일치 여부 검사
- 일치: 해당 영역 확정 (색 고정)
- 불일치: 경고 표시 + 영역 초기화

### 도형 일치 판별 로직
1. 색칠된 셀들의 좌표 수집
2. 좌상단 기준으로 정규화 (normalize)
3. 목표 도형의 정규화된 좌표와 비교
4. 회전/반전 허용 여부는 레벨별로 설정

- [ ] Canvas에 N x N 격자 렌더링
